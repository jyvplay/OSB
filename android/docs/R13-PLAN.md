# R13 pre-implementation thresholds

No S1–S30 gate is promoted. Available initially: Python/Git/GitHub API/Actions; local Java/Kotlin cache absent and restored before compilation. No independent agents/prover/physical devices/counsel. Workspace files matched remote f796ce9 byte-for-byte; Git metadata reconciled without replacing files.

Independent candidates: (1) bounded consumed-byte hashing for Files, not mutations; (2) quoted local-command lexical parsing, not a PTY; (3) explicit app-local action plans with real host dispatch, not dry-run text; (4) bounded UTC calendar-event serialization for explicit sharing, not CalendarContract scheduling; (5) original literal-cell XLSX export, not a LibreOffice rewrite or engine; (6) actual IME observation with plain ActivityScenario/UiAutomation, separate from Compose text injection.

Acceptance threshold for testability: public production API separately compiled, real behavioral fixtures/negative boundaries, source-bound receipts; actual Android execution before Android integration claims. Repairs inherit no trust. New parsers reject malformed/over-budget input, never silently enable gated operations. Typed data boundaries, ownership, consumed byte limits, Unicode/folding and formula injection get candidate-specific attacks.

Office request: inspect pinned LibreOffice interfaces/licensing/architecture, not copy/rephrase implementation. No clean-room-independence or legal-clearance claim: the same agent has inspected sources. Full1:1 parity must first name an upstream revision, platforms, formats, behaviors and tolerance/corpus; no finite small kernel or passed corpus certifies that universal contract. Source inspection is not a way to relicense derivative code. No LOK payload or source is incorporated into the main APK. Existing engine gate remains closed.

IME: preserve the failing R12 test initially. Measure active/default/enabled IME and actual window insets through Android, use real touch/accessibility editing without a Compose test-input substitute. Distinguish unavailable keyboard, harness effects and application clipping; do not infer the cause from a timeout.
