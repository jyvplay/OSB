# R52 Privacy, Tails-Light (`Prop 327`), `Recall` Provenance, & 25-Vector Local Hardware Defense PRD

## 1. `Recall` Privacy, Consent & DRM/Air-Gap Boundaries
1. **Local-Only Vaulted Storage (`Zero Cloud / Zero Telemetry`):** Every image, video, and music file captured by `Recall` is stored strictly inside the user's chosen local archive directory (`by-url`, `by-title`, or `custom` template), indexed in a local SHA-256 `manifest.recall.json` with optional `mat2` EXIF/GPS metadata scrubbing (`ExifGpsPrivacyScrubber` + `Mat2RecursiveMetadataScrubber`) and optional `AgeV1StreamCipherEnvelope` encryption at rest.
2. **Explicit `H-` Legal & OS Security Refusals:**
   - `:privacy` companion APK remains strictly **zero-`INTERNET`** (`check_r45_manifest_scope.py` enforced). `Recall` network stream harvesting runs exclusively inside `:feature:browser` / `:app` with visible recording badge and one-tap **Pause / Incognito Bypass** (incognito tabs default to `Recall = OFF` so amnesic browsing never writes viewed media to disk unless explicitly armed!).
   - Encrypted Media Extensions (`EME` Widevine, PlayReady, FairPlay, HLS `SAMPLE-AES`), `AudioAttributes.ALLOW_CAPTURE_BY_NONE`, and `WindowManager.LayoutParams.FLAG_SECURE` windows are **hard-refused** (`DRM_OR_SECURE_SURFACE_REFUSED`).

- **`TorOnionPowIntroQueue` (`:privacy`):** Implements clean-room RFC 7693 `BLAKE2b` + Tor Proposal 327 (`blake2b_32(P || ID || C || N || E || S) * E <= 0xFFFFFFFF`) effort verification, dynamic 5-minute suggested-effort adaptation under introduction-flood load, and bounded effort-priority eviction without disk persistence.
