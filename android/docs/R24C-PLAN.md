## A — admissible objects, access, resources, boundaries

- Tabletop: first-party launch targets, four surfaces (table/back/left/right), finite validated coordinates, immutable pins and piles, bounded cameras and named snapshots. Default overview is a slanted projective table occupying **83.16% of the scene viewport** (not the entire display including taskbar/windows). Wall focus expands a wall for actual >=48dp manipulation; overview thumbnails are not tiny fake touch controls. Panning is large but bounded, not infinite RAM/storage. Planned caps: 512 pins, 128 piles, 16 saved views, ±1,000,000 world units, <=2MiB encoded document. Resource counted: live/saved objects, bytes, viewport dp, font sp, and actual tests.
- Persistent arrangement: revision-checked, bounded, atomic same-directory publication, no reset on corrupt/unknown input. Same-UID writers cooperate via a file lock; no adversarial-OS/power-loss/disk-erasure theorem. UI drag previews are transient; one final change is persisted.
- Appearance: preserve Business/Art and Office Blue/Graphite; add original silver semantic palette. Dock target size is independent of glyph scale; overflow scrolls rather than crushing every logo into the screen. Phi may inform spacing, never overrides legibility or constitutes a universal beauty theorem.
- Media: explicit selected `content:` URI; genuine Android decoder/player, no autoplay, no background playback, no arbitrary URL extraction or DRM bypass. Commercial service links are canonicalized and explicitly handed to official external players; **not** certified embedded Spotify/YouTube/SoundCloud streaming. They cannot satisfy the unconditional-free-service contract.
- Mapping: offline geographic projection, attributed public-domain low-resolution land outlines if provenance is retrieved, bounded saved pins and distance calculation. No geolocation permission, geocoder, street routing, community tile scraping or fabricated map data.
- Privacy: existing no-INTERNET compartment remains separate. Observed input/IME/display changes discard active data and require an explicit empty restart. This mitigates a changed input environment, not passive/preexisting implants, malicious accessibility, firmware, OS, hypervisor or camera observation.

Quantifier order: for each admitted state and declared action/input in the finite test corpus, the implementation must preserve invariants and meet the specified result. We do not infer `for all devices/adversaries` from `there exists a passing emulator trace`. Floating geometry tolerance <=1e-6 normalized / 0.01dp in numerical checks; finite non-NaN values only. Normal semantic text contrast >=4.5:1, controls >=48dp; checking tokens or a finite viewport corpus is not global AX certification.

Adjacent problems not substituted: renderer vs generated screenshot; pure parser vs Android UI; pin list vs persistent drag; slanted background vs interactive planes; wide pan vs infinite capacity; link launch vs media playback; waveform/player clock vs audible physical speaker; coastline atlas vs city navigation; URL tracking removal vs anonymity; privacy APK vs Tails OS; policy observation vs hardware authenticity; local model tests vs full Office/browser engine; APK size vs total system footprint.
