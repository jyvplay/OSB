## D. NEGATIVE SPACE (`18` Failure Shapes + Explicit Modal Shortcut Failure Test)

1. **Singular matrix in `MINVERSE`**: $\det(A) = 0$ returns `CellErr.NUM` (`#NUM!`), never `NaN`/`Infinity`.
2. **Dimension mismatch in `MMULT(A, B)`**: `cols(A) != rows(B)` returns `CellErr.VALUE` (`#VALUE!`).
3. **Reversed or missing sheet names in 3D span `SUM(Q4:Q1!A1)` / `SUM(Ghost:Q2!A1)`**: reversed index order normalizes `min..max` cleanly; unknown endpoint sheet returns `#REF!`.
4. **Wasm `f64.const` (`0x44`) containing `0x0B` (`END`) inside its 8-byte IEEE-754 payload**: structured control-flow pre-scanner must advance `pc += 8` so `0x0B` inside `1.23456789` never terminates an enclosing `block`/`loop`/`if` early!
5. **Wasm `table.grow` exceeding declared table `max` limit**: returns `-1` (`0xFFFFFFFF` i32) per Wasm 2.0 spec without mutating table capacity.
6. **Cosmetic PDF "redaction" trap**: drawing a black rectangle over `/Tj` text leaves secret strings extractable in content stream; `PdfIncrementalSaveRedactor` physically scrubs matched text literals from content bytes AND purges metadata.
7. **Shallow Office metadata cleaning (`mat2` nested media trap)**: stripping `docProps/core.xml` while leaving GPS `APP1` EXIF inside `word/media/image1.jpg` fails audit; recursive ZIP re-packer scrubs nested JPEG/PNG streams.
8. **Bluetooth `BLUFFS` `7`-octet "KNOB-patched" session (`CVE-2023-24023`)**: `7` octets (`56` bits) is still offline brute-forceable across sessions via fixed derivation nonces; `BluetoothBluffsSessionGuard` rejects `< 16` octets and `SC -> LSC` role-switch downgrades.
9. **Wi-Fi MAC rotation without 802.11 sequence-number reset**: sequential 12-bit `seq_ctrl` (`2041 -> 2042`) trivially links old and new random MACs; `WifiProbeSequenceScrambler` re-seeds `seq_ctrl` on every MAC rotation.
10. **NFC HCE relay tunnel (`RTT = 38.5 ms`)**: valid APDU MACs still fail `NfcRelayDistanceBoundingGate` when measured `RTT > 12.0 ms` or nonce is replayed.
11. **Adobe `.cube` out-of-domain HDR RGB inputs (`> DOMAIN_MAX` or `< DOMAIN_MIN`)**: clamped to `[0, 1]` lattice coordinates before tetrahedral subdivision (`6` simplices) so indices never overflow `N - 1`.
12. **FSR 1.0 Lanczos2 negative-lobe halo/ringing around step edges**: `Fsr1EasuRcasUpscaler` clamps every EASU output sample to the local `2x2` texel `[min, max]` box.
13. **Tracker blocker over-blocking first-party scripts**: `EasyListTrackerFilterEngine` distinguishes `||tracker.example^$third-party` from first-party origin requests and honors `@@||allow.example^` exception rules + per-site disable switches.
14. **Browser profile data-directory traversal (`../default`)**: `BrowserProfileDirectoryIsolator` rejects non-canonical slugs and enforces disjoint cookie/storage/cache roots.
15. **RFB / VNC Server SecurityType downgrade (`SecurityType = 1 None`)**: `RfbVncHandshakeClient` refuses unauthenticated `None` sessions unless explicitly flagged loopback-test, requiring VeNCrypt TLS (`19`) or VNC Challenge-Response (`2`) with non-empty key.
16. **Matrix / XMPP copyleft or plaintext leak**: zero AGPL Signal code (`MS-06`); `MatrixXmppProtocolEngine` enforces `m.room.encryption` (`m.megolm.v1.aes-sha2`) room state checks and rejects `http://` homeservers.
17. **AEC3 NLMS filter divergence on near-end double-talk (`farEndEnergy -> 0` or speech burst)**: normalized step size $\mu / (\|x\|^2 + \epsilon)$ freezes adaptation during double-talk so near-end voice is never cancelled into NaNs.
