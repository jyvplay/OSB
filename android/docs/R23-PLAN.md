3. **Bounded lifetime:** fixed-capacity digit buffer, manual clear, background/focus-loss discard and monotonic inactivity expiry. Test cap/cap+1, old views, lost focus, recreation, deadline and clock reversal. Clearing references/arrays does not prove RAM/flash erasure.

Legitimate accessibility services and the OS remain trusted. Test actual flags and touch dispatch; no assertion that all overlay classes/AX tools are blocked.
