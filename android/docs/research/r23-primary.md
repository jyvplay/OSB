## Exact frontier, not substituted problems

Available achievability is scoped: Android ordinary-window/overlay/touch controls; keyboard-route removal in a small first-party UI; transient-state lifecycle; descriptor/UID containment already tested historically; bounded values-only Office projections. Available impossibility boundary is observational: an unprivileged app has no interface to distinguish a transparent keyboard logger that forwards identical events from an honest keyboard. Firmware/host control is outside its authority. This is an explicit model argument, not a new peer-reviewed impossibility theorem.

The open interface is implementation/integration evidence: real engine callbacks and compositor surfaces; exact Office engine licenses/fidelity/ABI; no-old-writer ownership plus distinct-UID shared-memory admission; all-device overlay/accessibility review; actual laptop/firmware/device controls and full guest+host footprint measurements. Neither documentation nor green scoped tests eliminates those interfaces.
